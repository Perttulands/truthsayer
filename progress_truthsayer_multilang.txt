## Iteration 10 - US-201: JS silent-fallback rules (callback-err-ignored, optional-chain-silence)
- Implemented `js_callback_err_ignored.go`: detects `(err, data) => { ... }` callbacks where err/error/e first param is never referenced in body; matches both `arrow_function` and `function_expression` node types; requires >=2 params and being inside `arguments` node (i.e., actual callback)
- Implemented `js_optional_chain_silence.go`: detects deep optional chaining (>3 `?.` operators) by counting `optional_chain` children in nested `member_expression` chains; only reports outermost chain (skips nested member_expressions with member_expression parent); deduplicates by start byte
- Registered both rules in `DefaultRegistry()`
- Created 4 test fixture files (positive + negative for each rule)
- 17 new tests total, all passing; full test suite green
- Learnings: tree-sitter node type for anonymous functions is `function_expression`, not `function`. `optional_chain` is a named child node with type `"optional_chain"` — need to check all children (not just named) via `ChildCount()`/`Child(i)` since it's a token. Parent-type check is the cleanest way to only report outermost chains.
**Summary:** Task: US-201 | Files: js_callback_err_ignored.go, js_optional_chain_silence.go + tests + fixtures | Tests: PASS | Review: PASSED | Next: US-202
